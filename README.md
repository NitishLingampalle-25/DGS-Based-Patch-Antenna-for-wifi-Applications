DGS-Based Microstrip Patch Antenna for 5 GHz Wi-Fi Applications

This project presents the design, simulation, and evaluation of a Defected Ground Structure (DGS) based rectangular microstrip patch antenna optimized for 5 GHz Wi-Fi (IEEE 802.11a/ac) applications.
A dumbbell-shaped DGS is etched on the ground plane to enhance current distribution, reduce surface-wave effects, and improve impedance matching.

🔍 Project Overview

The antenna is designed on an FR-4 substrate and tuned to operate around the 5 GHz ISM/Wi-Fi band.
The introduction of a dumbbell DGS increases the effective inductance of the ground plane, modifying the resonant characteristics and improving radiation performance.

This work explores how DGS can be used to:

Enhance gain

Reduce return loss

Improve impedance bandwidth

Achieve a more efficient current path without increasing antenna size

📌 Key Results

Operating Frequency: 5 GHz

Return Loss (S11): −24 dB at resonance

Gain: ~6.6 dB

Antenna Type: Microstrip Patch with Dumbbell-Shaped DGS

Simulation Tool: HFSS (Ansys)

📐 Features and Design Highlights

Compact rectangular patch antenna geometry

Dumbbell-shaped defect on ground plane to suppress surface waves

Optimized feed position for proper impedance matching

Improved radiation efficiency compared to traditional patch without DGS

Comparative analysis included (with and without DGS)
